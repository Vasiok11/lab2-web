# Augustin Center - Local Trading Hub Landing Page (Lab 3)

A modern, clean, and **fully responsive** landing page for **Augustin Center**, a local trading hub offering a variety of shops and services across three floors. This version has been completely rebuilt using **Tailwind CSS** and strictly adheres to a **0% JavaScript** requirement.

## About the Project

Augustin Center is a premier local destination designed to bring trusted businesses together under one roof. The center provides a convenient and friendly environment for the community's daily needs, featuring everything from pharmacies to electronics.

### Shops & Services Featured
- **Floor 1:** Pharmacy & Religious Goods
- **Floor 2:** TechnoPlus (Electronics) & Office Spaces
- **Floor -1:** Kids & Toys & Sweets Shop

## New Features & Changes (Lab 3)
- ✅ **Tailwind CSS Migration:** Completely replaced vanilla CSS with Tailwind utility classes and custom configuration.
- ✅ **100% JavaScript-Free:** Removed all JS. The mobile hamburger menu and interactive elements are powered entirely by pure CSS (`:focus`, `tabindex`, and `group-focus` hacks).
- ✅ **Full Mobile Responsiveness:** Fluid typography, flexible layouts, and optimized spacing for all mobile and tablet screens.
- ✅ **Interactive Mascot:** Added a custom SVG mascot that appears after a 3-second CSS delay and displays a speech bubble when tapped/hovered (using pure CSS).
- ✅ **Swipeable Shop Cards:** Converted the shop directory grid into a horizontal, snap-scrolling carousel on mobile devices to save vertical space.
- ✅ Clean, modern dark theme (grayscale and white) with smooth scrolling.
